# GLOW WITH JADEX

**Luminous Skin, Effortlessly Bottled** — A luxury botanical skincare and beauty e-commerce storefront built from scratch with HTML, CSS, and JavaScript.

## About the Project
GLOW WITH JADEX showcases clean botanical skincare formulas, a limited-edition Glass-Skin Duo promotional spotlight, verified customer love letters, and an interactive Vanity Bag drawer.

## Design & Aesthetic
* **Color Palette:** Warm Vanilla Cream, Champagne Pearl, and Soft Rose Petal surfaces grounded by Rich Espresso Cocoa and Warm Bronze accents.
* **Typography:** Pairs *Cormorant Garamond* editorial serif headings with clean *Plus Jakarta Sans* copy.

## Features
* **Bestselling Skincare Grid:** Interactive product cards with skin-type tags, hover zoom photography, and live bag additions.
* **Live $120 Free Gift Progress Bar:** Automatically tracks your subtotal inside the slide-out Vanity Bag drawer and unlocks a complimentary Silk Travel Pouch at $120.
* **Promotional Duo Bundle & Testimonials:** High-converting 20%-off Glass-Skin Duo banner paired with 5-star verified community reviews.

## Built With
* **HTML5** — Semantic beauty storefront layout
* **CSS3** — Custom variables, CSS Grid, Flexbox, and smooth hover transitions
* **Vanilla JavaScript** — Live vanity bag state, dynamic gift-threshold progress bar, and checkout confirmation
